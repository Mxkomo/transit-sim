# Règles de collaboration
Ce projet sert de projet personnel pour mes candidatures.
- Le code algorithmique (routing/, simulation/, demand/, optimization/,
  metrics/) est écrit par moi. Tu peux expliquer, relire, proposer des
  tests, mais pas écrire l'implémentation, sauf si je le demande
  explicitement.
- Tu peux écrire librement la configuration, les scripts de build et
  le code d'affichage web.
